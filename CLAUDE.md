# «Ось: тело и питание» — инструкции для Claude

Приложение канала об оздоровлении: курс упражнений с 3D-фигурой, раздел «Питание» (бывшее приложение по ЖКТ), привычки и прогресс. Автор — Егор. Цель: сначала для себя, потом бесплатно для всех, монетизация позже, развитие на весь мир.

Главный справочник по содержанию — документ «База знаний: канал об оздоровлении»:
https://claude.ai/code/artifact/aab0ff63-5d39-43b3-8aaa-98d7ecd4a1d2
Перед работой над содержанием сверяйся с ним. Если появилась новая информация по каналу — скажи Егору, что её нужно дописать в базу знаний.

## Как работать с Егором

- Отвечай по-русски, простым языком. Егор не программист: объясняй, что изменилось и где это увидеть, без технических подробностей, если он о них не спросил.
- Егор работает с iPad и телефона, компьютер — только на работе. Поэтому проверка на телефонных экранах обязательна.
- Перед большой переделкой коротко предложи план и дождись ответа.
- Порядок после каждой правки:
  1. `npm test` — телефоны 360–390 px, светлая и тёмная тема, без ошибок;
  2. посмотри скриншоты в `test-results/shots/`;
  3. коммит с понятным описанием на русском;
  4. публикация — только когда Егор скажет.
- В ответе коротко: что изменилось и где это найти в приложении.
- Если в данных есть противоречие или правило спорное — скажи честно. Поддакивания не нужны.
- Не проси пароли и доступы к аккаунтам (Instagram, GitHub и другие). Если нужен вход — Егор делает его сам.

## Выбор модели и экономия лимита

Какую модель для чего:

- **Haiku** — опечатки, мелкие правки текста, переименования, простые вопросы, оформление данных.
- **Sonnet** (по умолчанию) — обычные правки приложения, новые упражнения, тексты курса, несложные ошибки, тесты.
- **Opus** — большие переделки (плавность движений, разбиение app.js на модули, аккаунты и синхронизация), сложные ошибки, спорные решения по содержанию.

Правила:

- Если задача явно не для текущей модели, скажи об этом в начале: «Эту задачу лучше сделать на Opus» или «Это можно на Haiku». Переключает модель Егор.
- Большие задачи: план — на Opus, исполнение — на Sonnet в новом чате.
- Один чат — одна задача. Новая задача — новый чат: длинный чат расходует лимит быстрее.
- В начале чата читай только этот файл и `docs/ROADMAP.md`. Базу знаний открывай, только если задача про содержание.
- `src/app.js` (около 430 КБ) целиком не открывай — ищи нужный кусок поиском.
- Скриншоты смотри только нужные, не все подряд.
- В конце задачи допиши в `docs/ROADMAP.md` короткий итог: что сделано, что осталось. Новый чат начинается с него.

## Правила содержания

- Позиция автора: противник традиционной медицины; за натуропатию, гомеопатию, остеопатию, закаливание, солнце, голодание, заземление, свежий воздух; не против некоторых БАДов. Принцип: любую идею проверяем с обеих сторон одинаково строго.
- Шишонина упоминать только в списке литературы. В приложении — «Комплекс для шеи» со своими названиями упражнений.
- Инвентарь: никаких самодельных замен. Альтернативы — уличные турники, брусья и скамьи площадок, а также резинки и другой спортивный инвентарь из магазина для занятий дома или на улице.
- Дыхательные практики в курсе упражнений пока отложены.
- Теорию давать маленькими порциями, список литературы — в конце.
- Раздел питания построен на программе Козлова; имя Козлова — только в источниках.
- Лекарства от депрессии одним словом-термином не называть никогда. Пишем «лекарства от депрессии и тревоги».
- В материалах о здоровье — пометка, что это не замена врача. Предостережения пишем мягко, чтобы люди не боялись, без списков противопоказаний на входе.
- Информацию о «плоской земле» нигде не писать.
- Методы вроде «Детки» Иванова и Брэгга — отдельная категория «Радикальные и нетрадиционные методы», в план курса не входят.
- Раздельное питание: решение отложено, Егор проверяет на практике. Не менять без него.

## Устройство приложения

Разделы внизу: Сегодня, Движение (План, Карта тела, Упражнения), Питание, Прогресс.

- Анкета на входе (8 шагов): пол, возраст, этап жизни для женщин (беременность, после родов, менопауза), время в день, зоны, уровень, что есть под рукой (велосипед, турник, гантели, зал), место занятий, восточные практики.
- Пол меняет программу: женщинам — тазовое дно после родов, расхождение мышц пресса, уроки про цикл и кости, «Колени и прыжки», «Сильные кости» 40+, мягкий режим беременности; мужчинам — «Мужское здоровье: тазовое дно, сосуды, сила» и силовой день на базовом уровне.
- Три уровня: Базовый (бесплатный), Любительский и Продвинутый (платные). В тестовой версии открыты все.
- Прогресс: очки, уровни-позвонки от S1 до атланта, награды, в том числе за питание. Кнопка «Лёгкий день».
- Питание: этапы 0–6, протоколы, чек-лист, меню по совместимости, знания, «Нормы на день» для мужчин и женщин.

## Устройство кода

Это статическое веб-приложение без сборки: `index.html` подключает обычные (не модульные) скрипты по порядку, и **все они делят одну глобальную область видимости**. Порядок в `index.html` важен; новые файлы добавляй туда же. Переход на ES-модули и сборщик — отдельная задача (см. `docs/ROADMAP.md`), не делай его попутно.

| Файл | Что внутри |
| --- | --- |
| `index.html` | оболочка страницы и порядок скриптов |
| `css/base.css` | базовые правила (атрибут hidden и т. п.) |
| `css/app.css` | интерфейс: тема (светлая/тёмная через переменные), раскладка под телефон |
| `css/nutrition.css` | раздел «Питание» (стили внутри `.gut`) |
| `src/data/body-male*.js` | реалистичное мужское тело MakeHuman (CC0), 4 файла, готовые для движка — генерируются конвертером, руками не править |
| `src/engine/mannequin.js` | OS3D: скелет, решатель поз (solve), ключевые кадры (prep/sample), 2D-запасной рисовальщик |
| `src/engine/poses.js` | PZ: библиотека базовых поз и помощники (P, ft, hd, mirror) |
| `src/animations/*.js` | MOVES: анимации упражнений по группам (стоя, лёжа, на четвереньках, сидя, связки, цигун) |
| `src/engine/body-builder.js` | OS3B: процедурное тело (сейчас используется для женской фигуры) |
| `src/engine/rig.js` | OS3R: 17 костей тела и исходная поза REST |
| `src/engine/webgl.js` | OS3G: WebGL2-рисовальщик (двойные кватернионы, свет, тени, анатомический режим, лицо) |
| `src/data/course.js` | данные курса: уровни, упражнения EX, занятия SESS, недели WEEK/WEEK_M, зоны, теория, литература; правится прямо в этом файле |
| `src/app.js` | весь интерфейс в одной функции; внутри модуль GUT — раздел «Питание» |
| `tools/glb-to-engine/` | конвертер модели из Blender в тело для движка (см. README там) |
| `assets/models/` | исходные модели .glb |
| `tests/` | проверки Playwright |
| `docs/ROADMAP.md` | что дальше и найденные проблемы |

Движок: сантиметры и градусы, фигура смотрит в +Z, левая сторона — +X, ось Y вверх. Поза — набор параметров (`r`, `o`, `sp`, `ch`, `nk`, `hd`, `aL/aR`, `eL/eR`, `lL/lR`, `kL/kR`, ...) и цели для рук/ног (`HL/HR`, `FL/FR`) с обратной кинематикой. Анимация упражнения — `MOVES[id] = { kf: [{ p, d, h, a }], ease, m, props, ... }`: `p` — поза, `d` — длительность перехода, `h` — пауза, `a` — сила подсветки мышц. При показе переходы сглаживаются (`ease: 'cr'`), голова, локти и кисти слегка запаздывают, грудь «дышит» (`softMod` в `webgl.js`).

Публикация: приложение Claude на iPhone открывает страницу артефакта, но не загружает её отдельные файлы (стили, скрипты). Поэтому публикуем одним файлом: `npm run build` собирает `dist/os-app.html` (для артефакта claude.ai, по старой ссылке) и `dist/os-app.local.html` (для сайта: копируется в `docs/index.html` ветки `site`, адрес https://egorgusev2000-debug.github.io/os-app/). В репозитории файлы остаются раздельными.

Хранение: на claude.ai приложение синхронизирует прогресс через `window.claude.use('db')`. Вне claude.ai этого нет, и прогресс хранится только в браузере (`localStorage`, ключ `os-all-v1`). Своя база для аккаунтов — в планах.
