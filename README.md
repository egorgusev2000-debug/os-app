# Ось: тело и питание

Курс упражнений с 3D-фигурой, питание, привычки и прогресс — в одном приложении.

## Как работать: только iPad и телефон

Компьютер не нужен. Код лежит на GitHub, а Claude Code работает в облаке: сам скачивает проект, правит, запускает проверки и сохраняет изменения.

1. Открой приложение **Claude** на iPad или телефоне (или claude.ai/code в Safari) → раздел **Code**.
2. Выбери репозиторий `os-app` и начни новую сессию.
3. Напиши, что поменять, обычными словами. Claude Code правит, запускает проверки, смотрит скриншоты и сохраняет изменения в своей ветке на GitHub.
4. Чтобы изменения попали в основную версию, попроси Claude Code «создай pull request», а потом нажми **Merge** в приложении GitHub или на github.com.

Ставить Node.js, Git и распаковывать архивы не нужно — всё это делается в облаке. Пароли и входы в аккаунты (GitHub и другие) ты делаешь сам, Claude их не спрашивает.

Удобная первая фраза для новой сессии:

> Прочитай CLAUDE.md, README.md и docs/ROADMAP.md, установи зависимости и запусти проверки.

## Как смотреть приложение

- **Скриншоты.** После каждой правки Claude Code делает снимки всех вкладок на экранах телефонов (папка `test-results/shots/`). Попроси «пришли скриншоты» — они откроются прямо в приложении Claude.
- **Ссылка claude.ai.** Можно попросить Claude Code опубликовать текущую версию как страницу claude.ai — она откроется на iPad и телефоне.
- **Постоянная ссылка.** Следующий шаг — бесплатный хостинг (GitHub Pages, Netlify или Vercel, см. `docs/ROADMAP.md`): после каждого Merge приложение будет обновляться по одному адресу. Вход в аккаунт хостинга делаешь ты.

Адрес `http://localhost:5173` из `npm start` работает только внутри облачной сессии — с телефона его не открыть.

## Проверки

`npm test` — открывает приложение на 5 размерах телефона (360, 375, 390 px) в светлой и тёмной теме, проходит анкету и все вкладки, проверяет, что нет ошибок и ничего не вылезает вбок. Скриншоты — в `test-results/shots/`. Запускает Claude Code сам.

## Где что лежит

- `CLAUDE.md` — правила работы и содержания, устройство кода (Claude Code читает его сам).
- `docs/ROADMAP.md` — что делаем дальше.
- `tools/glb-to-engine/` — как обновить 3D-модель из Blender (это шаг для компьютера; без него можно обойтись).

Модель человека — MakeHuman (MPFB 2), лицензия CC0.
