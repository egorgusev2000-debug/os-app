## 1. Плавность движений

Что уже выяснено:
- Дело не в скорости телефона: расчёт позы на кадр занимает меньше 0,1 мс.
- У многих упражнений слишком мало ключевых поз: присед — 2, «собака мордой вниз» — 2, ходьба — 4. Движение — прямой переход между двумя позами, отсюда «робот».
- При показе все переходы сглаживаются одной кривой Катмулла — Рома по параметрам-углам (`ease: 'cr'` в `OS3G.mount`); у упражнений с 2 позами она даёт почти синусоиду без разгона и дотяжки.

Что сделать:
- Кривые разгона и торможения для каждого перехода: медленный старт, плавная остановка, короткая пауза в крайней точке.
- Больше промежуточных поз там, где траектория не прямая (присед: таз назад раньше, чем вниз; наклоны; «Приветствие солнцу»).
- Интерполяция поворотов через кватернионы вместо углов, чтобы не было рывков на больших поворотах.
- Лёгкая «живость» без лишнего: перенос веса, разное запаздывание звеньев.
- Движения с видео Егора (MediaPipe pose_landmarker_full.task): ролики сбоку по 2–3 повтора → ключевые кадры для ходьбы, «Приветствия солнцу», выпадов. С одной камеры сбоку хорошо видны сгибания, повороты и наклоны вбок — плохо.

## 2. Внешний вид фигуры

- Текстура кожи MakeHuman (сейчас кожа одного цвета): UV-координаты и текстура в шейдере тела.
- Причёска MPFB вместо простой «шапочки».
- Свет: мягкий контровой свет, затенение в складках (ambient occlusion), более живая кожа.
- Аккуратные края майки и шорт (сейчас местами «ступенька»).
- Женская модель MakeHuman (сейчас женская фигура — прежняя процедурная): тот же путь, что и для мужской, `window.OS3H_F` и `glbData('f')`.
- Ориентир — приложения с 3D-тренером: плавные зацикленные движения, студийный свет, спокойная камера.
